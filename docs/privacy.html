개인정보처리방침

시행일: 2026년 9월 3일 · 최종 업데이트: 2026년 10월 23일

원격 Agent는 npm 1.2.0의 agent 태그로 게시했습니다. 기본 연결은 읽기 전용이며 사용자가 별도로 편집 권한에 동의하면 Docs·Sheets 생성·수정을 지원합니다. 기존 읽기1.1.2와 latest1.1.1의 로컬 경로는 유지하며, Agent 설치 안내를 따릅니다. 원격 서버는 확인한 무료 조건과 제한된 사용량 안에서 운영합니다.

1. 적용 범위

이 개인정보처리방침은 Edu Workspace MCP(이하 “앱”)의 로컬 소프트웨어와 원격 Agent 연결이 Google 사용자 데이터에 접근하고 처리하는 방식에 적용됩니다. 운영 주체는 Edu Workspace MCP 프로젝트 운영자이며 문의 창구는 이 문서 마지막에 안내합니다.

기존 로컬 버전과 명시적인 private/legacy 경로는 사용자 컴퓨터에서 Google API와 직접 통신하고 Google 토큰을 로컬에 보관합니다. 새 원격 Agent 경로는 운영자의 Cloudflare 서버를 거쳐 Google API를 호출하고 암호화한 Google 갱신 토큰을 서버에 보관합니다. 일반 사용자는 자신의 Cloud 프로젝트나 Google JSON 파일을 준비하지 않고, 연결한 AI 앱에서 본인이 직접 Google 로그인과 선택한 읽기 또는 편집 권한 동의를 진행합니다.

2. 접근하는 Google 사용자 데이터

읽기 전용 원격 Agent는 사용자가 URL 또는 ID로 지정한 Google Docs 문서, Sheets 범위와 구성, Slides 내용, Forms 본문과 응답을 처리합니다. documents.readonly, forms.body.readonly, forms.responses.readonly, spreadsheets.readonly, presentations.readonly 다섯 권한만 요청합니다. 기본 연결에는 생성·쓰기가 없습니다. 별도로 편집 모드가 배포·활성화되고 사용자가 동의하면 documents와 spreadsheets가 각 읽기 권한을 대체하여 새 자료 생성과 지정한 자료의 내용·서식 수정을 지원합니다. Google 권한은 해당 서비스 자료 전체 관리 범위이지만 MCP에는 파일 삭제·공유·Drive 검색·Classroom·Gmail·이메일 신원 조회 도구를 추가하지 않습니다. 시트 구성 진단 결과에는 셀 값·수식·메모 본문을 포함하지 않습니다.

기존 로컬 고급 경로는 사용자가 별도로 선택하고 Google 권한 화면에서 승인한 범위 내에서 다음 데이터를 처리할 수 있습니다.

  • 앱이 사용하거나 생성한 Google Drive 파일 및 폴더
  • 앱이 생성한 파일과, 읽기 확장 모드에서 사용자가 URL 또는 ID로 지정한 Google Docs·Sheets·Slides 내용
  • 앱이 생성한 Google Forms와, 읽기 확장 모드에서 지정한 양식 구조·퀴즈 문항·응답·점수
  • 사용자가 담당하는 Google Classroom 수업·과제·학생 명단·제출 상태·점수

기존 자료를 읽는 서비스별 범위는 사용자가 --read로 명시적으로 선택할 때만 요청합니다. 구조 진단 도구는 Sheets의 셀 값과 수식 본문을 MCP 응답에 포함하지 않으며, Classroom 제출 대시보드는 학생 매칭에 사용한 사용자 ID를 결과 파일에 저장하지 않습니다. 앱은 전체 Drive, Gmail 또는 보호자 정보 범위를 요청하지 않습니다.

3. 데이터 이용 목적

Google 사용자 데이터는 사용자가 연결한 AI 앱에서 요청한 교육 업무에만 사용됩니다. 원격 Agent는 지정한 자료를 읽어 반환하고 연결 상태를 확인합니다. 별도 편집 연결에서는 사용자가 요청한 문서·시트를 만들거나 지정한 자료의 내용·서식을 수정합니다. 자료의 요약·분석은 사용자가 선택한 AI 앱에서 이루어집니다. 기존 고급 경로에는 자료 제작과 Classroom 업무 지원 기능도 있습니다.

4. 데이터 전송과 공유

원격 Agent에서는 Google 인증 코드·PKCE verifier·토큰과 요청한 자료가 운영자의 Cloudflare Workers에서 처리됩니다. Google 자료는 요청한 사용자와 연결된 AI 앱으로 반환되며, Cloudflare Workers·KV·D1은 서버 실행과 암호화한 인증 상태 보관을 위한 처리 기반으로 사용됩니다. Cloudflare의 전 세계 네트워크에서 처리될 수 있으므로 국내 처리만을 보장하지 않습니다. 기존 로컬 경로는 사용자 컴퓨터에서 Google 공식 API와 직접 통신합니다. 운영자는 광고·판매·신용평가·사용자 프로파일링 목적으로 자료를 제공하지 않습니다.

사용자가 연결한 AI 클라이언트는 도구 요청을 만들고 결과를 표시하는 과정에서 사용자가 제공한 내용이나 Google API 결과의 일부를 처리할 수 있습니다. Google 원본·집계·익명화·파생 데이터는 범용 AI/ML 모델의 생성·학습·개선에 사용할 수 없습니다. MCP는 특정 AI 제공자나 요금제를 내장하지 않으며, 사용자는 학습 공유가 비활성인 API·업무용 서비스 또는 외부 전송이 없는 오프라인 클라이언트만 연결해야 합니다. 학습에 사용하는 소비자용 서비스·무료 API·모델 허브로 Google 결과를 전송해서는 안 됩니다. 앱 운영자는 AI 모델 학습 데이터셋을 수집하지 않습니다.

5. 저장과 보관 기간

원격 Agent의 Google 갱신 토큰은 서버 키로 암호화해 Cloudflare D1에 보관합니다. Google 액세스 토큰은 API 요청 동안 메모리에서만 처리하며 저장하지 않습니다. 임시 OAuth 거래 정보는 암호화해 KV에 최대 10분 보관하고, 연결은 30일 미사용 시 만료됩니다. 연결·클라이언트 식별자와 만료·철회·요청 제한에 필요한 최소 상태도 보관합니다. 만료 기록은 실제 동작을 검증한15분 간격 정리 작업으로 제거합니다. 같은 예약 작업에서 공개된 공식 요금 안내를 확인하며, 이 확인에는 사용자 Google 자료나 인증정보를 보내지 않습니다. 서버에는 공개 요금 문구의 지문·확인 시각·성공 여부만 추가 저장합니다.

요청한 문서·시트·슬라이드·폼 본문을 서버 DB·캐시·로그·모델 학습 자료에 저장하지 않습니다. 사용자 기기의 ~/.edu-workspace-mcp-agent/remote/에는 별도 MCP 연결 자격증명만 저장하며 편집 연결은 remote-edit/에 분리합니다. 서버에는 중복 쓰기를 막는 요청 ID의 해시와 만료 상태를30일 이내 보관하며 쓰기 본문은 저장하지 않습니다. 기존 로컬 경로의 Google 토큰은 ~/.edu-workspace-mcp/token.json 등 사용자 기기의 비공개 설정에 보관합니다. Google 파일과 연결한 AI 앱의 대화·결과는 각 서비스의 보관 정책과 사용자 삭제 설정을 따릅니다.

6. 삭제와 권한 철회

원격 Agent는 설치한 버전의 disconnect 명령으로 해당 서버 연결을 차단하고 활성 Google 갱신 토큰의 암호문과 선택한 로컬 MCP 자격증명을 제거합니다. 같은 Google 프로젝트의 다른 일반 앱에 영향을 주지 않도록 프로젝트 전체 Google 동의는 자동 철회하지 않습니다. 서버에 접속할 수 없어 철회를 확인하지 못한 경우에는 완료됐다고 표시하지 않으며, 다시 시도하거나 운영자에게 삭제를 요청할 수 있습니다.

활성 DB에서 제거한 기록과 백업의 즉시 물리 삭제는 다릅니다. Cloudflare D1 Free의 복구 이력은 최대 7일이며, 복구 시 운영을 중단하고 암호화 키를 회전해 과거 연결을 재사용하지 못하게 합니다. Google 계정의 ‘서드 파티 앱 및 서비스’ 설정에서 Google 권한 전체를 철회할 수도 있으나 같은 프로젝트의 기존 일반 앱에도 영향을 줄 수 있습니다. 기존 로컬 버전의 연결 해제는 해당 버전의 안내를 따르며 Google 파일은 사용자가 Google Drive에서 관리합니다.

7. 데이터 보안

원격 Agent는 일반 웹 기능과 분리한 AI 전용 Web OAuth 클라이언트와 사용자가 선택한 읽기 또는 Docs·Sheets 편집 권한 다섯 개를 사용합니다. 실제 승인 범위의 누락·초과를 거절하고 PKCE(S256)·state·발급자·대상 서버·클라이언트·연결의 결합을 검사합니다. Google 토큰은 AI 앱에 발급하거나 전달하지 않고 수명이 제한된 별도 MCP 토큰을 사용합니다. 자동 OAuth URL 로그와 trace를 비활성화하며 코드·토큰·verifier·자료 본문·전체 예외를 로그에 출력하지 않습니다. 서버 비밀값은 공개 코드와 npm 배포물에 포함하지 않습니다.

사용자는 연결을 시작한 AI 앱과 Google 동의 범위를 직접 확인하고, 본인의 컴퓨터와 AI 앱을 안전하게 관리해야 합니다. 앱 이름은 자체 등록한 표시이며 신원 인증을 대신하지 않습니다.

8. Google API 제한적 사용 준수

앱의 Google API 사용자 데이터 이용은 Google API Services User Data Policy 및 Limited Use 요건을 준수합니다. 원본과 파생 데이터를 포함한 Google Workspace API 데이터는 요청한 기능에만 이용하며 범용 모델 학습·개선, 광고 또는 판매에 사용하지 않습니다.

The use of raw or derived user data received from Google Workspace APIs will adhere to the Google Workspace API User Data and Developer Policy and the Google API Services User Data Policy, including the Limited Use requirements. Google Workspace user data is never used, transferred or sold to create, train or improve foundational or generalized AI/ML models.

본 정책은 로컬 MCP와 원격 Agent의 읽기 및 별도 동의한 Docs·Sheets 편집 연결에 적용됩니다. 별도로 운영되는 개인용 Workspace Lab 웹앱의 서버 보관·AI 전송은 웹앱 개인정보 안내에 공개합니다.

9. 아동·학생 데이터

앱은 교사와 교육자의 업무 지원을 목적으로 합니다. 교육기관에서 학생 관련 정보를 처리하는 경우 사용자는 소속 기관의 정책, 관련 법령과 보호자 동의 요건을 확인해야 하며, 필요한 최소 정보만 입력해야 합니다.
