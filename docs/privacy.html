개인정보처리방침

시행일: 2026년 9월 3일 · 최종 업데이트: 2026년 9월 3일

1. 적용 범위

이 개인정보처리방침은 오픈소스 로컬 애플리케이션인 Edu Workspace MCP(이하 “앱”)가 Google 사용자 데이터에 접근하고 처리하는 방식에 적용됩니다. 앱은 사용자의 컴퓨터에서 Model Context Protocol 서버로 실행되며, 프로젝트 운영자는 사용자의 문서 내용이나 OAuth 토큰을 보관하는 별도 중앙 서버를 운영하지 않습니다.

2. 접근하는 Google 사용자 데이터

앱은 사용자가 Google 권한 화면에서 명시적으로 승인한 범위 내에서 다음 데이터에 접근할 수 있습니다.

  • 앱이 사용하거나 생성한 Google Drive 파일 및 폴더
  • Google Docs 문서 내용
  • Google Sheets 스프레드시트 내용
  • Google Slides 프레젠테이션 내용
  • Google Forms 양식 구조와 퀴즈 문항
  • 사용자가 담당하는 Google Classroom 수업과 사용자가 생성한 과제 정보

현재 버전은 Gmail, 학생 제출물, 학생 성적, 보호자 정보 또는 전체 학생 명단을 위한 OAuth 범위를 요청하지 않습니다.

3. 데이터 이용 목적

Google 사용자 데이터는 사용자가 AI 클라이언트에서 요청한 교육 업무를 수행하기 위해서만 사용됩니다. 예를 들어 수업안·학습지·평가표·슬라이드·퀴즈를 만들거나, 담당 Classroom 수업을 조회하고 과제 초안을 생성하는 데 사용됩니다.

4. 데이터 전송과 공유

앱은 사용자 컴퓨터에서 Google 공식 API와 직접 통신합니다. 프로젝트 운영자는 Google 사용자 데이터를 광고, 판매, 신용평가 또는 사용자 프로파일링 목적으로 제3자에게 전송하거나 공유하지 않습니다.

사용자가 연결한 AI 클라이언트는 도구 요청을 만들고 결과를 표시하는 과정에서 사용자가 제공한 내용이나 Google API 결과의 일부를 처리할 수 있습니다. 해당 처리는 사용자가 선택한 AI 서비스의 개인정보처리방침과 설정을 따릅니다.

5. 저장과 보관 기간

Google OAuth 액세스·갱신 토큰은 기본적으로 사용자의 컴퓨터 내 ~/.edu-workspace-mcp/token.json에 사용자 전용 파일 권한으로 저장됩니다. 프로젝트 운영자의 서버에는 저장되지 않습니다. 앱이 생성한 문서와 교육 자료는 사용자의 Google 계정에 저장되며 Google의 보관 정책과 사용자의 삭제 설정을 따릅니다.

6. 삭제와 권한 철회

사용자는 npx edu-workspace-mcp disconnect를 실행해 로컬 토큰을 삭제할 수 있습니다. Google 계정의 ‘서드 파티 앱 및 서비스’ 설정에서도 앱의 접근 권한을 언제든 철회할 수 있습니다. 앱이 생성한 Google 파일은 사용자가 Google Drive에서 직접 관리하고 삭제할 수 있습니다.

7. 데이터 보안

앱은 최소한의 OAuth 범위를 요청하고, 게시 및 공유와 같이 다른 사용자에게 영향을 주는 작업에는 별도 확인 절차를 둡니다. 공개 저장소에는 사용자의 OAuth 토큰이나 Google 인증 코드가 포함되지 않습니다. 사용자는 운영체제 계정과 AI 클라이언트를 안전하게 관리해야 합니다.

8. Google API 제한적 사용 준수

앱의 Google API 사용자 데이터 이용은 Google API Services User Data Policy 및 Limited Use 요건을 준수합니다.

9. 아동·학생 데이터

앱은 교사와 교육자의 업무 지원을 목적으로 합니다. 교육기관에서 학생 관련 정보를 처리하는 경우 사용자는 소속 기관의 정책, 관련 법령과 보호자 동의 요건을 확인해야 하며, 필요한 최소 정보만 입력해야 합니다.

10. 방침 변경 및 문의

기능이나 데이터 처리 방식이 변경되면 이 문서를 업데이트하고 상단의 최종 업데이트 날짜를 변경합니다. 개인정보 및 OAuth 관련 문의는 kimjj0709@gmail.com으로 연락해 주세요.
