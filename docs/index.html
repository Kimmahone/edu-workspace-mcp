Google Workspace for Education × AI

교사의 말이
수업 자료가 됩니다.

Edu Workspace MCP는 AI가 Google Docs, Sheets, Slides, Forms, Drive와 Classroom에서 교사의 요청을 실제 결과물로 만들도록 연결하는 오픈소스 도구입니다.

GitHub에서 시작하기 작동 방식 보기
  • 사용자 컴퓨터에서 실행
  • Google 공식 API 사용
  • 민감한 토큰은 로컬 저장

교육 업무에 맞춘 도구

반복 작업은 줄이고, 수업에 집중하세요.

한 번의 요청으로 여러 Google 교육도구를 연결해 일관된 수업 패키지를 만들 수 있습니다.

01

수업 자료 제작

수업안과 학습지를 Docs로, 차시별 발표 자료를 Slides로 생성합니다.

02

평가 설계

과정중심평가 표와 루브릭을 Sheets로, 정답·배점이 있는 퀴즈를 Forms로 만듭니다.

03

Classroom 연계

담당 수업을 확인하고 과제 초안을 만든 뒤, 교사의 명시적 승인 후 게시합니다.

04

Drive 정리와 협업

교과·단원별 폴더와 파일을 만들고, 공유는 대상과 권한을 확인한 뒤 적용합니다.

작동 방식

Google 계정은 사용자가 직접 연결합니다.

  1. 설치MCP를 AI 클라이언트에 연결합니다.
  2. 권한 확인Google 화면에서 요청 범위를 직접 확인하고 승인합니다.
  3. 로컬 실행요청은 사용자 컴퓨터에서 Google API로 직접 전달됩니다.
  4. 언제든 해제로컬 토큰 삭제와 Google 계정 권한 철회가 가능합니다.

Local-first privacy

사용자 데이터로 별도 사업을 하지 않습니다.

프로젝트 운영자는 문서 내용이나 OAuth 토큰을 별도 중앙 서버에 수집·저장하지 않습니다. 사용자가 요청한 작업을 수행하기 위해 로컬 MCP가 Google API와 직접 통신합니다.

현재 버전은 학생 제출물, 성적, 보호자 정보 또는 Gmail 접근 권한을 요청하지 않습니다.
