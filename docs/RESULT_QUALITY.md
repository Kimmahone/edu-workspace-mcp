# 결과물 디자인 구현 및 검증 — 2026-09-26

## 구현

- 클래식 리포트·모던 워크스페이스·웜 에디토리얼 3가지 디자인. 편집·미리보기·Google 저장·HWPX·편집본 백업에 선택값 전달.
- Docs: 제목·절 번호·강조 상자·표 음영·A4·표 안 여백·반복 머리행. 수업안의 활동 설명 열을 63%로 배분.
- Sheets: 대시보드와 실행 보드, 실제 수식·도넛 차트·상태 드롭다운·조건부 색상·고정 머리행·필터. 사용자가 입력한 문자열은 수식으로 실행하지 않음. 집계 범위는 생성 당시 업무 행 기준.
- Slides: 편집 가능한 텍스트·도형으로 표지와 카드 구성. 긴 본문을 여러 장으로 분할하고 글자 크기 조절.
- Forms: 문항 번호·5문항 단위 섹션·배점·정답·정오답 해설. 선택적으로 미리 꾸민 원본 양식을 새 파일로 복제.
- Kordoc: 보고서 프리셋과 표 프로필로 글꼴·헤더 색·배경·테두리·열 너비·쪽 설정 적용.
- 예시 12종의 내용과 다운로드 파일 재생성. 갤러리 썸네일도 실제 디자인 렌더러 출력으로 교체. 12종 × PDF/PNG/HWPX/Markdown/JSON.
- AI 프롬프트: 유형별 필수 구조와 작성 기준, 교사 발문·학생 활동·평가 증거, 시간 합계, 문항 해설, 실행 역할·기한, 확인되지 않은 정보 처리 등을 명시.

## 참고 자료

사용자가 제시한 Google Docs의 제목 상자, 메타정보 표, 학습 문제 강조, 과정안과 평가표 구조를 읽고 참고했다. 원본은 수정하지 않았다.

범정부오피스는 공식 소개의 표준 서식·문단 체계·표 스타일 자동화 방향을 참고했다. YouTube 영상 본문은 직접 재생 확인하지 못했다.

## 확인한 범위

실제 연결 계정의 Drive에 전용 예시 폴더를 만들고 Docs 2개·Slides·Sheets·Forms 각 1개를 생성했다. 원본 참고 문서와 기존 사용자 파일의 내용·공유 권한은 변경하지 않았다. 결과 ID는 로컬 `outputs/designed-google/results.json`에 있다.

- Docs·Slides·Sheets: Google에서 PDF로 내보내 화면 확인. 표 여백과 제목 배치 보완.
- Sheets: 실제 집계값 전체 6개·완료 1개·진행 중 1개·기타 4개 및 차트 확인.
- Forms: 5문항과 정답·배점·해설의 API 재읽기 확인.
- HWPX: 실제 생성 파일의 내용과 서식 프로필 재읽기 확인.

## 남은 환경 확인

1. Gemini/GPT 실제 키가 없어 변경된 프롬프트의 실서비스 응답 품질은 아직 검증하지 않았다. 예시는 키 없이 편집·저장할 수 있다.
2. Google Forms API는 테마 직접 설정을 지원하지 않는다. 머리글 3종을 제공하며 원본 양식 연결 순서는 `WORKSPACE_LAB_START.md`의 C절에 있다. 실제 테마 원본을 연결한 복제와 다중 사용자 접근 권한은 운영 계정에서 확인해야 한다.
3. HWPX는 이 환경에서 한글의 조판 화면을 렌더링하지 못했다. Google Docs/PDF 미리보기와 한글의 쪽 배치는 같다고 보장하지 않는다. 배포 전 한글에서 파일을 열어 표·글꼴·쪽 배치를 확인한다. 복잡한 서식의 원본 유지 수정은 Kordoc 경고와 결과를 검토해야 한다.
4. 이번 변경은 로컬 앱에 반영했다. 공개 서비스 배포에는 기존 운영 안내의 OAuth·DB·API 키 설정이 필요하다.
