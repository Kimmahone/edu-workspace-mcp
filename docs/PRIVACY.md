# 개인정보 처리 안내 초안

이 문서는 공개 Google OAuth 검증과 실제 서비스 배포 전에 운영자 정보·연락처·호스팅 정책을 반영해 확정해야 하는 초안입니다.

## 로컬 stdio 버전

- 배포용 데스크톱 OAuth 클라이언트 식별자는 앱에 포함되며, 사용자의 Google 액세스·갱신 토큰은 사용자의 컴퓨터에만 저장됩니다.
- MCP 서버는 요청을 처리하기 위해 Google API와 직접 통신합니다.
- 프로젝트 자체는 사용자의 문서 내용이나 토큰을 별도 중앙 서버로 전송하거나 수집하지 않습니다.
- AI 클라이언트가 MCP 도구에 전달한 내용은 해당 AI 서비스의 데이터 정책을 따릅니다.

## 저장 위치와 삭제

- 기본 설정 폴더: `~/.edu-workspace-mcp`
- OAuth 토큰 삭제: `npx edu-workspace-mcp disconnect`
- Google 계정의 제3자 앱 액세스 화면에서도 권한을 철회할 수 있습니다.

## 처리하는 데이터

사용자가 호출한 도구에 따라 파일 이름·내용, Drive 파일 ID, Classroom 수업·과제 정보가 Google API 요청에 포함될 수 있습니다. 현재 버전은 학생 제출물, 성적, 보호자 정보나 Gmail을 요청하지 않습니다.

## 원격 버전

호스팅형 MCP는 아직 제공하지 않습니다. 향후 제공할 경우 토큰 암호화, 보관 기간, 로그 정책, 하위 처리자, 데이터 삭제 절차를 포함한 별도 개인정보처리방침을 공개합니다.
