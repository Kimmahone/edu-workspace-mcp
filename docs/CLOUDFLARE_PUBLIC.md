# Workspace Lab · 함께 쓰는 웹앱

Google 계정으로 로그인하면 자신의 Drive에 문서·시트·슬라이드·설문을 저장할 수 있습니다. 별도 프로그램이나 MCP 설치가 필요하지 않습니다.

## 시작하기

1. 예시 갤러리에서 원하는 양식을 선택합니다.
2. 제목과 내용을 직접 고치고 미리보기를 확인합니다.
3. ‘연결 및 이용 안내’에서 자신의 Google 계정으로 로그인합니다.
4. 저장할 파일 종류를 고른 뒤 Google에 저장합니다. 결과는 로그인한 사람의 Drive에 생성됩니다.
5. 한글 문서실에서 HWP/HWPX/DOCX를 열거나 HWPX를 내려받을 수도 있습니다.

학교 Google 계정은 학교 관리자의 외부 앱 허용이 필요할 수 있습니다. 일반 Google 권한 동의 화면은 정상입니다.

## 제공하는 기능

- 예시 편집, 초등 성취기준 검색, 수업·업무 문서 작성.
- 접속한 기기에서 실행하는 한글 문서 읽기·수정·변환·비교.
- 본인 Google 계정에 Docs·Sheets·Slides·Forms 저장.
- 선택적으로 Classroom 권한을 연결하고 자신이 담당하는 수업에 과제 초안을 작성. 게시 전 별도 확인.
- Google 로그인과 작업 기록은 계정별로 분리합니다.

공개 웹앱에서는 AI 생성·다듬기를 아직 제공하지 않습니다. 예시를 편집하거나 직접 작성한 내용을 사용할 수 있습니다.

## 자료 보관과 연결 해제

문서 원본과 작성 중인 초안은 브라우저에서 처리합니다. 다른 기기에서 이어서 작업하려면 ‘편집본 보관’으로 JSON 파일을 내려받아 옮깁니다. 로그인 정보와 짧은 작업 기록은 암호화해서 계정별로 보관합니다. 로그인은 8시간, 저장 확인 자료는 최대 15분, 작업 기록은 최대 7일 후 만료됩니다.

로그아웃은 현재 로그인만 종료합니다. Google Drive 파일은 삭제하지 않습니다. Google 계정의 서드 파티 앱 설정에서 앱의 접근을 철회할 수 있습니다. 서버에 남은 계정·작업 기록 삭제는 kimjj0709@gmail.com으로 요청할 수 있습니다. 자세한 내용은 [개인정보 안내](/privacy)를 확인하세요.

## 운영자용 배포

개인용 Worker·D1·암호화 키는 유지하고 공개용 `workspace-lab-public` Worker와 별도 D1을 사용합니다. 공개용은 `PUBLIC_APP=true`를 명시한 환경에서만 여러 Google 계정을 허용합니다. API 키가 잘못 등록되더라도 공개용 AI 경로는 차단합니다.

검수를 통과한 `edu-workspace-mcp` 프로젝트에 공개용 웹 OAuth 클라이언트를 별도로 만듭니다. 공개 주소의 origin과 `/auth/callback`을 등록하고 기존 개인용·MCP 클라이언트는 유지합니다. `APP_SECRET`, `GOOGLE_WEB_CLIENT_ID`, `GOOGLE_WEB_CLIENT_SECRET`만 공개 Worker의 Secret으로 등록합니다. 기존 DB를 복사하거나 새 암호화 키로 덮어쓰지 않습니다.

```sh
npm run cloud:public:build
npx wrangler deploy --config wrangler.public.jsonc
```

공개용 설정의 D1 ID는 실제로 생성한 공개용 DB를 지정합니다. `wrangler.jsonc`는 기존 개인용 배포를 계속 관리합니다.
