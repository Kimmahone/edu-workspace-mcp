# Install this MCP from a GitHub URL

When the human asks to install this repository, use the released npm package rather than cloning and building by default.

1. Confirm the OS and the intended host: Claude Code (`claude`), Codex (`codex`), Claude Desktop (`claude-desktop`), Cursor (`cursor`), or all installed hosts. Infer only when the current host is unambiguous; otherwise ask one short question.
2. Check `node --version` and `npm --version`. Node 22+ is required. If missing, explain the official Node installation step; do not bypass OS permissions or silently install unrelated software.
3. Check the published version. **1.1.1 and earlier ignore unknown flags and do not support `--workspace-readonly`. Never pass that flag to those releases or fall back to their login.** This source targets the reviewed 1.1.2 Agent version. Check that exact npm version is published; the `agent` tag is separate from legacy `latest` 1.1.1 to preserve existing users. Stop if the exact reviewed version is not published.
4. Run the verified version's `setup` to inspect installed hosts, then `setup <host>` or `install <host>` for the selected hosts. Installation preserves other MCP servers and the old `edu-workspace` registration. The new registration is `edu-workspace-agent`, using exactly five read scopes and a separate token directory.
5. Stop before Google login and consent. Give the human the same version's `login` command to run themselves. Do not read/download/copy OAuth JSON or tokens, enter passwords, click consent, or request Classroom scopes. Docs/Sheets edit scopes may be requested only when the user explicitly asks for creation/editing and only with a verified edit-capable release.
6. Registration is not authentication. Report each host's registration separately from user login and a verified Google read.

Default installation uses Docs, Forms body, Forms responses, Sheets, and Slides read-only scopes. `--legacy` is an explicit advanced/web compatibility choice; never select it or `--read` for an ordinary installation request.
