# 함께 만드는 1박 2일 여행

## 여행 개요
- 날짜: [함께 정하기]
- 목적지: [후보 2~3곳 비교 후 결정]
- 이동 방법: [대중교통 / 자가용]

## 1일 차
| 시간대 | 활동 | 확인할 것 |
| --- | --- | --- |
| 오전 | 출발과 이동 | 집합 장소, 승차권 |
| 점심 | 현지 식사 | 식이 제한, 예약 |
| 오후 | 산책 또는 전시 관람 | 운영 시간, 날씨 |
| 저녁 | 숙소 체크인과 대화 | 체크인 시간, 준비물 |

## 2일 차
아침 식사 → 주변 산책 → 점심 → 귀가. 이동 사이에 30분 정도 여유를 둡니다.

## 공동 예산
| 항목 | 예상 비용 | 정산 방식 |
| --- | --- | --- |
| 교통 | [입력] | 각자 / 공동 |
| 숙박 | [입력] | 인원수로 나누기 |
| 식비·활동 | [입력] | 영수증 모아 정산 |

## 출발 전 체크
- 예약 취소 조건 확인
- 날씨와 이동 경로 확인
- 충전기, 개인 상비용품, 신분증 준비
- 예약 담당과 정산 담당 정하기
