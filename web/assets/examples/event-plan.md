# 책으로 연결되는 하루

> 운영 방향: 책을 소개하고, 질문을 나누고, 다음 읽기를 약속하는 참여형 행사입니다. 날짜·장소·담당자는 실제 계획에 맞게 확정하세요.

## 행사 개요
| 목적 | 대상 | 운영 시간 |
| --- | --- | --- |
| 읽기 경험과 질문을 나누기 | 참여를 희망하는 학습자 | 90분 예시 |

## 당일 운영표
| 순서 | 시간 | 활동 | 담당 역할 |
| --- | --- | --- | --- |
| 열기 | 10분 | 안내와 오늘의 질문 | 진행 |
| 만나기 | 25분 | 추천 책 1분 소개, 책 둘러보기 | 모둠 진행 |
| 나누기 | 35분 | 질문 카드 토의 | 기록 |
| 연결하기 | 20분 | 다음 읽기 약속과 회고 | 전체 |

## 준비 업무와 완료 기준
| 시점 | 할 일 | 완료 증거 |
| --- | --- | --- |
| 일주일 전 | 장소·참여 규모·역할 확정 | 운영표와 안내문 |
| 3일 전 | 추천 책·질문 카드 취합 | 모둠별 자료 묶음 |
| 전날 | 동선·장비·자료 점검 | 점검표 확인 |
| 종료 후 | 회고와 자료 정리 | 결과 기록 1장 |

## 상황별 운영 대안
| 상황 | 대응 |
| --- | --- |
| 참여 인원 변화 | 모둠 크기 조정, 진행 역할 재배치 |
| 장비 사용 불가 | 인쇄 질문 카드와 기록지 사용 |
| 이동 혼잡 | 이동 순서 지정, 통로 확보 |

## 돌아보기
질문 카드와 회고를 모아 참여자가 새로 발견한 생각, 불편했던 동선, 다음 행사에서 바꿀 점을 정리합니다.
